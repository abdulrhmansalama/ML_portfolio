# Abdulrhman Salama Portfolio

## Folder structure
- `index.html` — home
- `about.html` — profile + education
- `projects.html` — projects + project photos
- `certificates.html` — certificate grid + click-to-open details
- `contact.html` — contact page
- `style.css` — shared design
- `script.js` — navigation, animation, reveal effects, certificate modal and contact form
- `images/My/` — personal / achievement photos
- `images/certificates/` — certificate scans
- `images/projects/` — project photos

## Notes
- Alexandria University is intentionally kept in the Education section rather than the main hero headline.
- MEC and WE achievement photos appear only inside their related certificate detail modal.
- The supplied graduation-project photos are used in the Projects page.
- The contact form uses `mailto:` and does not require a backend.
