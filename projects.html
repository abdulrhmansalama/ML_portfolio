Data Analysis & Machine Learning

Uber & Lyft Cab Prices Analysis

A comprehensive data analysis and machine learning project based on approximately 100,000 Uber and Lyft ride records.

Project Overview

The project analyzes ride pricing using multiple features related to the ride, including geographic information, distance, cab company, and other ride-related attributes.

Technical Workflow

  • Data exploration and preprocessing
  • Geospatial feature transformation
  • Haversine distance calculation
  • Exploratory data analysis and visualization
  • Uber vs. Lyft pricing analysis
  • Surge pricing analysis
  • Supervised machine learning
  • Unsupervised learning and clustering
  • Dimensionality reduction using PCA
  • Deep learning experiments
  • Streamlit dashboard deployment

Technologies

Python Pandas NumPy Matplotlib Seaborn Plotly Scikit-learn XGBoost TensorFlow Keras Streamlit

Machine Learning

The project includes supervised models such as XGBoost, Random Forest, and Gradient Boosting, together with unsupervised techniques including K-Means, DBSCAN, and PCA. Deep-learning experiments included LSTM and Autoencoders.
